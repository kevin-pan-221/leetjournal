# Minecraft textures

The PNG files under `items/` are unmodified default Minecraft Java Edition 1.21.4
item textures, © Mojang Studios / Microsoft.

Source mirror:
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4/assets/minecraft/textures/item

Leather's grayscale base is rendered using the default undyed tint `0xA06540`,
with its separate overlay left untinted. Tint source:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/items/leather_chestplate.json

These third-party game assets are not original LeetJournal artwork and are not
covered by any license applying to LeetJournal source code. LeetJournal is not
affiliated with or endorsed by Mojang Studios or Microsoft.

## Worn equipment and stand

`equipment/humanoid_*.png` and `equipment/humanoid_leggings_*.png` are the
default 64×32 worn armor atlases from the same edition/version, under:
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4/assets/minecraft/textures/entity/equipment

`equipment/armor_stand.png` is the default 64×64 wooden stand texture:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/textures/entity/armorstand/wood.png

The same attribution and third-party-asset notice above applies to these files.

## Bookshelves and chest

`blocks/bookshelf.png` and `blocks/oak_planks.png` are unmodified default 16×16
block textures from the same edition/version:
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4/assets/minecraft/textures/block

`furniture/chest.png` is the unmodified default 64×64 single-chest atlas:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/textures/entity/chest/normal.png

These assets have the same Mojang Studios / Microsoft attribution and third-party
notice above. They are bundled locally; no Minecraft installation is needed.

## Enchanting table and book

`blocks/enchanting_table_{top,side,bottom}.png` are the default 16×16 table textures.
The base uses the 16×12×16 model and cropped side UVs from:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/models/block/enchanting_table.json

`furniture/enchanting_table_book.png` is the default 64×32 cover/page atlas:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/textures/entity/enchanting_table_book.png

The same attribution and third-party-asset notice applies.

## Enchanting glyph particles

`particles/sga_a.png` through `sga_z.png` are the 26 unmodified 8×8 default
Standard Galactic Alphabet particle sprites listed by Minecraft's enchant effect:
https://github.com/InventivetalentDev/minecraft-assets/blob/1.21.4/assets/minecraft/particles/enchant.json

Texture source directory:
https://github.com/InventivetalentDev/minecraft-assets/tree/1.21.4/assets/minecraft/textures/particle

The same Mojang Studios / Microsoft attribution and third-party notice applies.
